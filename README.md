# พอร์ตโฟลิโอออนไลน์ — สวิตตา ฟุ้งลัดดา (เปียโน) | Personal Engineering Portfolio

เว็บไซต์รวบรวมผลงานทางวิศวกรรมซอฟต์แวร์ ประสบการณ์การทำงาน รางวัลระดับประเทศ และเรซูเม่ของ **สวิตตา ฟุ้งลัดดา (Sawitta Fungladda / เปียโน)** นักพัฒนาซอฟต์แวร์แบบ Full-Stack และปัญญาประดิษฐ์ (Computer & AI Engineering, UTCC)

---

## ✨ ฟีเจอร์หลักของเว็บไซต์

- **Modern Editorial & Bento Grid UI**: จัดวางข้อมูลสำคัญในรูปแบบการ์ด Bento อ่านง่าย สแกนข้อมูลสำคัญได้ภายในไม่กี่วินาที
- **Interactive Project Mockups**: ภาพจำลองอินเทอร์เฟซเฉพาะตัวของทั้ง 5 โปรเจคหลัก (`drone-dashboard`, `expense-planner`, `Project-LineOA`, `SAR`, `IOT-26`)
- **In-Browser CV Preview Modal**: ปุ่มเปิดดูไฟล์เรซูเม่ฉบับเต็ม (`CV_Sawitta_Fungladda.pdf`) บนหน้าเว็บได้ทันทีโดยไม่ต้องโหลดออกนอกหน้า พร้อมตัวเลือกเปิดแท็บใหม่หรือดาวน์โหลดไฟล์
- **Bilingual Switcher (TH / EN)**: สลับภาษาไทยและภาษาอังกฤษได้ทันทีแบบไม่ต้องโหลดหน้าใหม่
- **Dark / Light Theme Toggle**: รองรับโหมดมืดและโหมดสว่างอย่างสมบูรณ์ด้วย Tailwind CSS v4

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Typography**: Geist Sans, Geist Mono & Noto Sans Thai

---

## 🚀 การรันโปรเจคในเครื่อง (Local Development)

```bash
# ติดตั้งแพ็กเกจ
npm install

# รันเซิร์ฟเวอร์สำหรับพัฒนา (http://localhost:3000)
npm run dev

# บิลด์สำหรับใช้งานจริง (Production Build)
npm run build
```
